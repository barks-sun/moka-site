墨卡 Moka 隐私政策

更新日期：2026 年 8 月 26 日

墨卡 Moka（以下简称“墨卡”或“我们”）是一款阅读想法记录与书摘整理工具。我们重视你的隐私，并尽量让数据处理保持透明和可控。

1. 我们处理哪些数据

你创建、导入或编辑的书摘、评论、标签、书籍信息、资料库、分享样式、头像、背景图片和导出的分享图片，会在 App 中用于展示、整理、搜索、分享和导出。当前版本默认将这些内容保存在你的设备上。

如果你使用微信读书连接功能，墨卡会处理你主动同步或导入的微信读书书架、笔记、阅读进度、阅读统计和公开参考信息。

如果你启用可选的智能整理功能，墨卡会处理你主动提交的书摘、评论、书籍信息、提示词和生成结果。

如果你在 Apple 设备上启用可选的 iCloud 自动备份或点击手动备份，墨卡会将本地数据库副本及备份时间、来源设备名称、App 版本、数据库版本和文件校验值保存到你个人 Apple ID 对应的 iCloud 容器。每台设备保留最近 3 份备份；微信读书 Key 与 AI API Key 不会进入备份。

2. 权限使用

墨卡可能请求以下系统权限：

  • 相册读取权限：用于选择头像、背景图片或其他你主动选择的图片。
  • 相册写入权限：用于保存你生成的分享图片。
  • 文件访问能力：用于通过系统文件选择器导入或保存你主动选择的文件。
  • 剪贴板访问：仅在你点击“从剪贴板粘贴”等明确操作时读取剪贴板内容。

墨卡不会在后台持续读取相册、文件或剪贴板。

3. API Key 和安全存储

如果你连接微信读书或启用可选的外部整理服务，需要自行提供对应服务的 API Key。API Key 会保存在系统安全存储中，并仅在以下情况下使用：

  • 你保存或测试微信读书、外部服务连接；
  • 你主动同步微信读书书架、笔记、阅读统计或公开内容；
  • 你主动请求外部服务生成、润色或整理文本。

你可以在 App 内清除已保存的 API Key。

4. 第三方服务

墨卡本身不运营账号系统，也不提供广告追踪服务。以下功能会在你主动使用时向第三方服务发送数据：

  • 微信读书连接：请求会发送到微信读书接口 https://i.weread.qq.com/api/agent/gateway。请求中可能包含你的微信读书 API Key、接口参数，以及同步所需的数据。微信读书返回的数据会按你的操作保存到墨卡中。
  • 智能整理：请求会发送给你当前配置的外部服务商，例如 DeepSeek 或自定义 OpenAI-compatible 服务。请求中可能包含你选择的书摘、评论、书籍信息、提示词和上下文。请只在你信任对应服务商时启用此类功能。
  • 版本更新检查：Android 版启用自动检查后，会在启动或回到前台时请求本站公开的 releases/latest.json，每 24 小时最多一次；手动检查时也会请求该文件。请求用于获取版本号、下载链接和校验值，不会上传你的书摘、标签或阅读内容。你可以在设置中关闭自动检查，安装包只会在你主动确认后下载。iOS 版通过 App Store 更新。
  • iCloud 备份：当你在支持的 Apple 设备上启用自动备份、手动备份或恢复备份时，相关备份文件会由 Apple iCloud 保存、下载或删除。墨卡运营方不会接收或代管这些备份。
  • 系统分享：当你使用系统分享面板时，分享图片会交给 iOS、Android 或桌面系统和你选择的目标 App 处理。

第三方服务对数据的处理、保存和删除规则由其各自隐私政策约束。

5. 数据上传和收集

使用书摘管理、编辑、搜索、标签整理和导出分享图等基础功能时，墨卡不会自动把你的内容上传到墨卡运营方服务器。你启用 iCloud 备份后，备份只会保存到你个人 Apple ID 的 iCloud 容器。

当你主动使用微信读书连接或外部整理服务时，相关内容会发送给对应第三方服务以完成你请求的功能。墨卡不会出售你的个人信息，也不会为了跨 App 或网站跟踪而收集数据。

6. 数据保存和删除

当前版本中，书摘等数据主要保存在你的设备中，直到你在 App 内删除、清除 API Key、删除相关文件或卸载 App。你可以在 iCloud 备份页面删除指定备份；关闭自动备份只会停止后续自动备份，不会自动删除已有版本。

如果第三方服务已经接收了你主动发送的数据，请按照对应服务商提供的方式查询、导出或删除。

7. 儿童隐私

墨卡不是面向儿童的 App。我们不会有意向未成年人提供定向广告或跨 App 跟踪能力。

8. 信息安全

墨卡会尽量使用系统安全能力保护你的数据，例如使用系统安全存储保存 API Key，并通过 HTTPS 与第三方服务通信。但任何网络传输和设备存储都无法保证绝对安全，请妥善保管你的设备、系统账号和 API Key。

9. 政策更新

如果墨卡的功能或数据处理方式发生重要变化，我们会更新本隐私政策，并在适当位置提示你查看。

10. 联系我们

如对本隐私政策或数据处理有疑问，可以通过 App 设置页中的反馈 QQ 群 838325027 联系我们。
