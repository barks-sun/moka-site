# 墨卡 Moka

墨卡是一款面向个人阅读者的阅读想法记录与书摘整理工具。

它可以帮助你同步和整理阅读书架、书摘、心迹、想法和阅读记录；当你愿意保存或分享时，也可以把喜欢的片段生成干净的书摘卡片。

官网：https://barks-sun.github.io/moka-site/
