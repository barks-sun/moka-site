同步范围

用同步清单控制导入范围。

先在同步清单里选择要整理的书。默认书架和笔记导入只显示清单中的内容，微信读书书架里的其他收藏不会被移除。

其他功能

心迹

没有书名的记录会归入“心迹”，名称可以在设置里修改。

分享卡片

选择布局、背景和文字，生成并保存书摘图片。

智能整理

配置服务后手动使用；保存前会先显示生成结果。

数据与备份

书摘默认保存在本机。

核心书摘与资料库默认保存在设备中。Apple 设备可选择备份到个人 iCloud，并按设备保留最近 3 份；微信读书 Key 与 AI API Key 不进入备份。
